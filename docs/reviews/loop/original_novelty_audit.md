## What was audited, and the honest limitation

> **The historically scored train/test files do not exist as files.** `scripts/run_surface.py` and `scripts/run_composition.py` build their splits in memory from the generator plus a seed and persist only the score manifest, so there is no archived scored JSONL to re-open. This audit is run on **deterministically regenerated splits** built from the **recorded config/seed** by executing the scoring scripts' own split code (AST-extracted verbatim, not re-implemented). It is *not* an audit of an archived original, because no archived original was ever produced.

Regeneration is exact for a fixed generator source: `make_task` is a pure function of `(operation, task_id, seed, id_set, family)` via `random.Random(seed)` and never touches global RNG state. The cross-check below re-runs the same split code against the generator blob at the manifest commit to show whether the model-visible content matches the scoring-time source.
